# Hozy's Translator

A Valenced plugin for Discord (Android) that lets you translate any message with a single long-press tap. The result appears only to you as a local ephemeral message — no one else in the chat sees it.

---

## Features

- **Long-press to translate** — tap and hold any message, then hit *Translate* in the action sheet
- **Ephemeral output** — translation shows up as a local bot message visible only to you
- **Three translation engines** — Google Translate (default), Microsoft Translator, or Brave Translate
- **Auto-detect** — automatically figures out the source language if you leave it on Auto
- **80+ languages** — pick any source and target language from the built-in list
- **Settings page** — switch engine and change languages without leaving Discord
- **Clean teardown** — all patches are removed when the plugin is disabled, no memory leaks

---

## Installation

1. Open Discord and go to **Settings → Valenced → Plugins**
2. Tap the gear icon in the top-right corner
3. Paste the repository URL and tap **Add repository**
4. Go back to the Plugins page and tap **[+]**
5. Find **Hozy's Translator** and install it

---

## How to use

1. Long-press any message in a server or DM
2. Tap **Translate** in the action sheet
3. The translation appears right in the chat — only you can see it

---

## Settings

Go to **Settings → Valenced → Plugins → Hozy's Translator → Settings**

| Option | Description |
|---|---|
| Translation Engine | Switch between Google, Microsoft, or Brave |
| Translate From | Source language (default: Auto Detect) |
| Translate To | Target language (default: Arabic) |
